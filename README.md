# homebrew-aeolus

Homebrew tap for the Aeolus trierarch, the process on a machine that crews the ships of an Aeolus fleet.

```sh
brew install thomashendrickx/aeolus/aeolus-trierarch
```

`brew upgrade aeolus-trierarch` moves to a newer release.

The formula in `Formula/` is written by the release workflow of
[aeolus-fleet-trierarch](https://github.com/ThomasHendrickx/aeolus-fleet-trierarch) at each release: do not edit it here.
It installs the release binary for the machine's system and chip, checked against the checksum the release recorded.
